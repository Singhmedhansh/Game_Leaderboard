# Free Fire Tournament Leaderboard

Vite + React (JSX) leaderboard for the 21-team college Free Fire event. The app ships with the seeded roster, live Group A / Group B standings, protected match entry, finals preview, and a shareable state link for WhatsApp.

## Admin
- Passkey: `admin_2026`
- Group split: first 11 teams are Group A, remaining 10 are Group B
- Scoring: placement ladder plus 1 point per kill

## Scripts
- `npm run dev`
- `npm run build`
- `npm run preview`

## Deploy
1. Build the app from the `freefire-leaderboard` folder.
2. Deploy the same folder to Vercel.
3. Use the match editor to save each group round, then copy the share link and post it in WhatsApp.
