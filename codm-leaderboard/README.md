# CODM Event Leaderboard (minimal scaffold)

This is a minimal, mobile-first static scaffold for a Call of Duty: Mobile (CODM) event leaderboard.

How to run

- Open `index.html` directly in a browser, or serve with a simple HTTP server from this folder:

```bash
# Python 3
python -m http.server 8000

# then open http://localhost:8000
```

What this includes

- `index.html` — hero, prompt input, simple controls
- `styles.css` — responsive esports-style CSS
- `app.js` — minimal logic to add teams and update scores
